# ローカルサーバー起動方法

## 目的

`frontend/` と `design/portal/` は ES Modules を使っているため、HTMLファイルを直接開かず、ローカルHTTPサーバー経由で確認する。

## 起動

リポジトリルートで以下を実行する。

```sh
python3 -m http.server --bind 127.0.0.1 --directory . 4174
```

別のターミナルから確認する場合は、以下のURLを開く。

```text
Frontend:
http://127.0.0.1:4174/frontend/index.html

Design Portal:
http://127.0.0.1:4174/design/portal/index.html
```

## ルート確認

Frontend SPAは以下のhash routeを持つ。

```text
http://127.0.0.1:4174/frontend/index.html#/home
http://127.0.0.1:4174/frontend/index.html#/port-keys
http://127.0.0.1:4174/frontend/index.html#/reports
http://127.0.0.1:4174/frontend/index.html#/shopping-list
http://127.0.0.1:4174/frontend/index.html#/wallets
```

## 停止

サーバーを起動したターミナルで `Ctrl + C` を押す。

起動したターミナルが分からない場合は、`4174` を使っているプロセスを確認して停止する。

```sh
ss -ltnp 'sport = :4174'
kill <PID>
```

`ss` の出力に `users:(("python3",pid=430760,fd=3))` のように表示された場合、`pid=` の値を指定する。

```sh
kill 430760
```

## ポートが使用中の場合

`4174` が使用中の場合は、別のポートを指定する。

```sh
python3 -m http.server --bind 127.0.0.1 --directory . 4175
```

この場合、URLのポート番号も `4175` に置き換える。
