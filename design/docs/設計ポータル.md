# 設計ポータル

## 構成

`design/portal/` は3ペイン構成とする。

- 左ペイン: `screenRegistry` 由来の画面一覧
- 中央ペイン: `frontend/js/pages/` の描画関数を使った画面プレビュー
- 右ペイン: Screen詳細、コンポーネント詳細、Action詳細、computed style

## プレビュー

ポータル専用の画面コピーは作らない。

`design/metadata/screenRegistry.js` から `frontend` の画面描画関数とmock ViewModelを参照し、中央ペインに描画する。

## インスペクタ

左ペインで画面を選択した時点で、右ペインのScreen詳細に `screenRegistry` の情報を表示する。

プレビュー内クリック時に以下を取得する。

- `event.target.closest("[data-screen-uid]")`
- `event.target.closest("[data-component-uid]")`
- `event.target.closest("[data-action-uid]")`

取得したUIDをもとに、`screenRegistry`、`componentRegistry`、`actionRegistry` の内容を右ペインに表示する。

## Computed Style

選択DOMに対して `getComputedStyle()` を実行し、以下を表示する。

- `width`
- `height`
- `padding`
- `margin`
- `color`
- `background-color`
- `font-size`
- `font-weight`
- `border-radius`
- `display`
- `gap`
