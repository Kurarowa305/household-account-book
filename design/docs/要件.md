# 家計簿アプリケーション機能要件

## お財布管理

| 機能 | 要件 | 備考 |
| --- | --- | --- |
| お財布ID | 各お財布にIDを付与し、管理単位を分ける |  |
| お財布名 | 各お財布に名称を設定できる |  |
| お財布リスト | 登録済みのお財布を一覧表示する | メニューの一番下に配置する |
| お財布削除 | お財布カード右上のメニューから削除できる | 論理削除とし、最低1件のお財布は残す |

## HOME画面

| 機能 | 要件 | 備考 |
| --- | --- | --- |
| 予算表示 | 選択中のお財布の予算を表示する |  |
| 出費金額表示 | 選択中のお財布の出費金額を表示する |  |
| 残高表示 | 予算から出費を差し引いた残高を表示する |  |
| 目標コメント表示 | 月ごとに設定した予算の目標コメントをMonthly Summary右上に表示する |  |
| 出費割合グラフ | 予算を100%として、その中での出費割合を円グラフで表示する |  |
| 出費内訳グラフ | 出費内訳の詳細を円グラフで表示する |  |

## 貯金額表示機能

| 機能 | 要件 | 備考 |
| --- | --- | --- |
| 貯金総額表示 | 貯金の総額を表示する | 1年でリセットしない |
| 年間貯金総額表示 | その年の貯金総額を表示する |  |
| 貯金額ロジック | `(予算 + Bank:入金) - (出費合計 + Bank:出金)` で算出する |  |

## 入力機能

| 機能 | 要件 | 備考 |
| --- | --- | --- |
| 入力カテゴリ | 予算、Bank、食費、日用品、特別費、固定費、変動費に分けて入力できる |  |
| 日付選択 | 日付に関しては一括選択できる |  |
| 予算入力 | 月始めに1回、予算金額とその月の目標コメントを設定する | 同じ月に再保存する場合は既存の予算設定を更新し、追加作成しない |
| 食費入力 | 品目、金額を入力する |  |
| 日用品入力 | 品目、金額、お店を入力する | 歯車アイコンから品目の追加、一覧確認、削除ができるようにする。品目削除は論理削除とする |
| 特別費入力 | 事柄、金額を入力する |  |
| 固定費入力 | Rent、Internetの金額を設定する | 設定保存時、選択月の月初めに月1回分のRent/Internetエントリを作成または更新する |
| 変動費入力 | 電気、ガス、水道を入力する |  |
| Bank入力 | 入金、出金を入力する |  |
| 入力履歴 | 入力履歴の表と合計表示を確認できる | 各ポートキーから画面遷移する |
| 入力フロー | シンプルで一度に完結する入力フローにする |  |
| 入力画面 | 1画面内でカテゴリに分かれた入力欄を表示する |  |

## データ操作ポリシー

| 項目 | 要件 | 備考 |
| --- | --- | --- |
| 編集操作 | 登録済みデータには編集操作を設けない | Budgetは月次予算設定として当月分のみ再保存による更新を許容する |
| Port Key削除範囲 | Port Keys画面から削除できるのは当月分の入力データのみ | 前月以前のデータには削除ボタンを表示しない |
| 論理削除 | Wallet、Daily Goods Itemsは論理削除とする | 画面上は非表示にする |
| 物理削除 | Wallet、Daily Goods Items以外の削除対象データは物理削除とする | Budget Entriesは削除対象外 |

## レポート機能

| 機能 | 要件 | 備考 |
| --- | --- | --- |
| 月末締めレポート生成 | 月末締めのレポートを生成する |  |
| 月次レポート内容 | HOME画面相当のデータ、各ポートキー内の表、一言コメントを含める | Category Totalでは変動費をElectricity、Gas、Waterに分けて表示する |
| 月次PDF出力 | 月次レポートをPDF出力する |  |
| 月次サマリーリセット | 月次PDF出力後、Monthly Summaryのみ翌月分へリセットする | ポートキー内の入力データは削除しない |
| 月次振り返り | 月次振り返りを記録できる | コメント記録機能を含む |
| 年間レポートPDF出力 | 12月に年間レポートをPDF出力する |  |
| 年間レポート内容 | 総予算、総出費、総貯金額を表示する |  |
| 食費の変動 | 食費の変動を折れ線グラフで表示する |  |
| 日用品の積み立て棒グラフ | 日用品の積み立て棒グラフを表示する | 横軸は品目 |
| 日用品最安値一覧 | 日用品の各品目について、最安値月、金額、店を表示する |  |
| 特別費一覧 | 特別費をテーブルで表示する |  |
| 年間コメント一覧 | 一言コメント12か月分を表示する |  |
| データ削除 | 年次データを削除できる | データ操作ポリシーに従う |
| 新年度切り替え | 新年度へ切り替えられる | アプリから去年のデータにアクセスするすべはない |

## Shopping List

| 機能 | 要件 | 備考 |
| --- | --- | --- |
| LINE送信 | Shopping Listに入力したものをLINE宛に送れるようにする | 定期実行でもよい |
| LINE連携入力 | LINEで入力したものをShopping Listに送る | 要調査 |
